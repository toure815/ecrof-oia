# OIA Audit — Complete Reference Guide

## Overview

- **36 Yes/No questions** — 9 per pillar, weighted 5/3/1
- **3 economic questions** — hours_per_week_lost, hourly_labor_cost_range, annualRevenue
- **1 contact step** — name, business, email
- **Form field IDs:** q1–q36
- **Answers:** "yes" or "no"

---

## The 4 D's (Pillar Names)

| Pillar | Questions | Sub-themes |
|--------|-----------|------------|
| **Diagnose** | q1–q9 | Decision Clarity, Workflow Awareness, Role Understanding |
| **Define** | q10–q18 | Workflow Structure, Tool Integration, SOP Maturity |
| **Design** | q19–q27 | Automation Readiness, Delegation Reliability, Execution Consistency |
| **Deploy** | q28–q36 | Performance Tracking, Bottleneck Removal, Momentum Maintenance |

---

## Weight System

Each sub-theme has 3 questions following a **5 / 3 / 1** weight pattern:

| Position | Weight | Role |
|----------|--------|------|
| 1st question (q1, q4, q7, etc.) | **5 — Critical** | Pain signal |
| 2nd question (q2, q5, q8, etc.) | **3 — Standard** | Capability check |
| 3rd question (q3, q6, q9, etc.) | **1 — Indicator** | Habit/practice check |

**Max per pillar:** 3 triplets × (5+3+1) = **27 points**
**Max total:** 4 pillars × 27 = **108 points**

---

## Polarity

The 1st question in every triplet is **NEGATIVE** (pain-framed: Yes = bad).
The 2nd and 3rd questions are **POSITIVE** (strength-framed: Yes = good).

**Scoring logic:**
- NEGATIVE question: Yes → 0 points, No → full weight
- POSITIVE question: Yes → full weight, No → 0 points

**Negative (Yes = 0):** q1, q4, q7, q10, q13, q16, q19, q22, q25, q28, q31, q34
**Positive (Yes = weight):** q2, q3, q5, q6, q8, q9, q11, q12, q14, q15, q17, q18, q20, q21, q23, q24, q26, q27, q29, q30, q32, q33, q35, q36

## ROI Calculation

```
hourlyRate     = annualRevenue / 2080
yearlyHours    = hours_per_week_lost × 52
hoursRecovered = yearlyHours × 0.40          (40% recovery)
yearlySavings  = hoursRecovered × hourlyRate
monthlySavings = yearlySavings / 12
```
