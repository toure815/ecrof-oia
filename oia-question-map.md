## POLARITY ISSUE (CRITICAL)

The n8n Calculation Engine scores `isYes(q) === true` as earning points.
However, **12 of 36 questions are negatively framed** (q1, q4, q7, q10, q13, q16, q19, q22, q25, q28, q31, q34) — meaning "Yes" = a problem exists = should score 0, not earn points.

### How the Framer form handles this:
The Multi-Step Form Logic boxes in Framer show:
- **Negative questions**: `Yes = 0`, `No = [weight]` (e.g., q1: Yes=0, No=5)
- **Positive questions**: `Yes = [weight]`, `No = 0` (e.g., q8: Yes=3, No=0)

### What this means:
The Framer form likely converts answers before sending to n8n:
- If user answers "Yes" to a negative question → Framer sends `q1: "no"` to webhook
- If user answers "No" to a negative question → Framer sends `q1: "yes"` to webhook

**This polarity flip MUST be handled** either in:
1. The Framer form (before sending) — appears to already be doing this
2. OR in the n8n Calculation Engine (by adding a negativeQs array)

> Verify in Framer that the multi-step form logic correctly flips negative answers before POSTing to n8n.
